Detailed Description

This file implements a dual-core light sensor and anomaly detection system using FreeRTOS. It pins two tasks to core 0, the light detecter (which reads from a photoresister and calculates the SMA which is the average of the last 5 readings) and the Light Level Display which the light level data and SMA data to be displayed on the LCD. The next two tasks are pined to core 1, which includes the Anomaly Alarm which toggles the LED when the environment is too dark or too bright and the Prime Calculation task that repeatedly calculates all the prime numbers from 2 to 5000.
