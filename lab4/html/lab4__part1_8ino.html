Detailed Description

This implements a algorithm that preempts tasks based on the shortest remaining time. The three tasks include LED Blinker, LCD counter, and alphabet printer. Based on which task has the shortest remaining execution time, the scheduler preempts any current task that is not that task and then resumes the next task with the shortest exectution time until all tasks are complete.

◆ srtfSchedulerTask()

void srtfSchedulerTask ( void * pvParameters)

SRFT scheduler task has the highest prioirty and runs continuously to manage three worker tasks (LED, Counter, Alphabet). it tracks the shortest task and the minTime, comparing each task's remaining execution with minTime and setting it to shortestTask if it is smaller. It suspends tasks if they are not the shortestTask and resumes the execution time of the shortestTask. It evaluates which task has the smallest remaining execution time, suspends all other tasks, and resumes the task with the shortest remaining time.
